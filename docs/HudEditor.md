# 局内 HUD 编辑器

2026-11-18 开发实现。公开的 v0.1.0 Release 和本机原安装 DLL 不含本页新增功能；本轮构建和测试没有发布新版本，也没有保留覆盖安装。

## 进入与保存

1. 安装本轮构建的 `OC2HudCustomization.dll` 和 **ModSettings 1.1.1 或更新版本**，重新启动游戏。
2. 在没有远程玩家的本地普通厨房，打开 ModSettings → HUD 自定义，打开总开关，点击其下方的“进入 HUD 编辑模式”。入口关闭设置页，再取得原生暂停和输入占用。
3. 点击带边框的元素选中。拖动主体移动，四边分别改宽高，四角等比缩放；面板也能直接输入位置、大小、宽高倍率和不透明度。
4. 按 **反引号 `** 保存退出并恢复画面。普通字母、鼠标松开和其他键不触发保存；该次反引号不会重新打开 ModSettings。无效数字或写盘失败时保留编辑状态，修正后再次保存。

编辑器借用原生 Main/UI/Camera 暂停层、玩家/UI 输入 suppressor 和鼠标占用，不修改 `Time.timeScale`。场景离开、加载、总开关关闭、远端加入或异常会丢弃草稿，释放自己的占用；不会清除其他菜单已有的暂停。

## 白名单、选择与临时预览

面板包含计分板、倒计时、切菜、烹饪、搅拌、炉温表盘、洗碗、灭火八类。

- 左侧勾选控制该类是否允许鼠标选中；取消勾选不撤销已保存的显示参数。
- 点击中间类别名可以直接编辑或恢复该类默认值，元素透明或移出屏幕时也能找回。
- 右侧“预览”勾选临时显示本关**已经创建、目前隐藏**的同类 UI；进度显示使用原生半满进度条。可以同时勾选多类，随后点击显示出来的元素拖动。
- 取消预览、保存退出、取消会话或停用插件会恢复原来的显隐及显示进度。预览不写入 cfg，也不改变食材处理进度、计时、完成状态或配方。
- 本关尚未创建实例时预览开关置灰；不会为不存在的炉具、火灾或搅拌机创建业务对象。若 UI 的更上层父对象本身停用，也不会为了预览而启用整层游戏对象。
- 不透明度为 0 的类别仍保留该参数；从类别名称调整不透明度或重置即可恢复。预览不强行覆盖用户的不透明度设置。

预览只临时修改原生显示对象及其进度条，不调用 `CookingUIController.SetState` 等会触发声音、完成动画和状态转换的入口。可见性被其他拥有者改动时让权并保留诊断。

## 参数单位与持久化

同类实例共用相对参数：拖动一条切菜进度条会给其他切菜条增加相同偏移，后创建的实例也会继承；不会把所有进度条堆到一个绝对位置。

| 参数 | 单位与范围 |
| --- | --- |
| X / Y | 屏幕宽/高的百分比，-100%～100%；Y 正值向上 |
| 大小 | 原生显示倍率，0.2～3 |
| 宽度 / 高度 | 原生显示的额外轴向倍率，0.25～4 |
| 不透明度 | 0%～100% |
| Editable | 是否允许鼠标选择该类别 |

位置使用屏幕 XY；不提供含义不同的世界 Z 偏移，不改变悬浮条跟随的游戏实体。宽高改变目前作用于整组显示，文字、圆形装饰可能随单轴拉伸；四角缩放可保持当前纵横比例。

八类各 7 项，共 **56 个隐藏原生 BepInEx ConfigEntry**，位于 `HudEditor.<类别>` 分区，全部 `Browsable=false`，不逐项显示在 ModSettings。原有 9 项可见设置保持原键、类型和默认值，新增的可见入口只有一个编辑操作。编辑中不随拖动保存；退出时仅提交变化，统一保存一次，取消时保留原配置。

按钮和编辑器文案跟随游戏的 12 种语言；语言未就绪或未知时使用英文，语言刷新继续复用现有 SDK 通知机制。

## 支持边界与证据

当前编辑入口限无远程玩家的普通厨房。Horde 不适配；生存模式的独立双计时控制器没有纳入本轮实现。对战双队显示沿用同类相对参数，没有逐队独立配置或完整对战验收。

本轮真实 Unity 验证使用实际 ModSettings 页面入口、原生计分板/倒计时及原生进度显示 fixture。点击/拖动属于脚本事件，未冒充物理鼠标验收；fixture 只建立显示对象，没有修改真实订单或伪造烹饪业务。

- 编辑器实机：**82 项**断言，实际画面 **3840×2160**；包含预览显隐恢复、半满显示、同类拖动、后建实例继承、保存/取消、原有暂停保留及关闭恢复。
- 计分板移动 **(+307.2, -259.2) px**；右边宽度 **709.75→851.70 px**；角落缩放后 **936.87×304.37 px**。
- 倒计时移动 **(-268.8, -324) px**；上边调整高度 **222→266.4 px**，底边保持。
- 两条切菜显示同时由原生 anchor Y **0.1→0.2**，对应屏幕向上 **216 px**；退出预览恢复隐藏及原显示进度。
- 同一正式 DLL 的菜谱回归 **65 项**通过，实际画面 **1920×1080**。本轮已有新 cfg，未触发旧版迁移分支，因此与早期 73 项包含迁移的结果数量不同。

两轮最终测试均已退出自有进程，原 DLL、cfg、共享日志和原存档核对恢复，临时测试 DLL 移除，恢复冲突 0。所有失败 run 保留，后续修复不将失败证据改写为 PASS。完整摘要见 [hud-editor-verification.json](evidence/hud-editor-verification.json)。原始截图和几何保存在对应本地 `.validation/` 目录，不随源码提交。

未完成：物理鼠标/手柄实测、12 语言全部实际字形与长文本排版、每类进度 UI 的完整真实业务生命周期、远程玩家加入的双端验收、双队/生存/Horde 模式适配。静态支持的类别不等于其全部业务已实机覆盖。
