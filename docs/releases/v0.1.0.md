# OC2 HUD 自定义 / OC2 HUD Customization v0.1.0

## 中文

- 首次发布独立 HUD 自定义 MOD：调整菜谱卡片及容器内容图标的大小、每行数量，并分别设置菜谱、空位加号和食材图标透明度。
- 菜谱按包含炊具的完整显示高度换行；裁去主菜卡上方多余纸面，保留一条时间进度条。新菜谱沿第一行滑入，在横移末段快速落位后展开食材与烹饪步骤。
- 提供 9 项原生 BepInEx 配置，可选接入 ModSettings；配置名称和说明跟随游戏的 12 种语言，默认英文，并在语言变化后通知设置页刷新。
- 默认保留原生显示，只调整本机 HUD。兼容开发版旧 GUID 配置的首次迁移，保留旧文件，已有新配置优先。

## English

- First release of the standalone HUD mod: adjust recipe-card and container-icon scale and columns, with separate opacity controls for recipes, empty-slot plus signs, and ingredients.
- Recipe rows use the full rendered height, including cookware. Extra paper above the main dish is hidden while one timer bar remains. New cards enter along the first row, move quickly into place near the end of the slide, then reveal ingredients and cooking steps.
- Includes 9 native BepInEx settings and optional ModSettings support. Setting labels and descriptions follow all 12 game languages, default to English, and notify the settings page when the language changes.
- Defaults preserve the native display and affect only the local HUD. Legacy development-GUID settings migrate once; the old file is retained and an existing new configuration takes priority.

## 日本語

- 独立 HUD MOD の初版です。レシピカードと容器内アイコンの大きさ・1行の個数を変更でき、レシピ・空き枠のプラス表示・食材アイコンの透明度を個別に設定できます。
- 調理器具を含む実際の表示高さでレシピを改行します。メイン料理の上に余る紙を隠し、時間バーは1本残します。新しいカードは最上段から入り、横移動の終盤で配置先へ素早く移動してから食材と調理手順を展開します。
- BepInEx 標準設定9項目と任意の ModSettings 連携に対応します。設定名と説明はゲームの12言語に追従し、既定は英語です。言語変更後に設定画面へ更新を通知します。
- 初期値では標準表示を維持し、ローカル HUD のみに適用します。開発版の旧 GUID の設定は初回のみ移行し、旧ファイルを保持します。新しい設定ファイルが既にある場合はそちらを優先します。

## 安装 / Installation

1. 预先安装 BepInEx 5 / HarmonyX。Requires the Windows Mono build of Overcooked! 2 with BepInEx 5 / HarmonyX.
2. 下载 `OC2HudCustomization-v0.1.0.zip`，将其中的 `OC2HudCustomization.dll` 放入 `BepInEx/plugins`，重启游戏。Extract the DLL into `BepInEx/plugins` and restart the game.
3. ModSettings 1.1.0+ 为可选设置面板。配置文件为 `BepInEx/config/com.ch3ngyz.plugin.overcooked2.hudcustomization.cfg`。ModSettings is optional; the cfg works independently.
4. 从本地开发版升级时，覆盖旧 DLL，避免同时安装两份 HUD 插件。旧 cfg 仅在新 cfg 不存在时导入，不会覆盖已有新设置。Replace the old DLL; keep only one copy of this plugin.

## 验证与限制 / Verification and limits

- 已有真实 Unity 厨房测试通过 73 项断言，覆盖 1/2 列、0.5/1/2 倍大小、跨行炊具净空、分阶段入场、关闭恢复与旧配置迁移；测试后存档、配置与临时插件恢复核对通过。
- 桌面规则/配置/迁移 841 项、实际 ModSettings 提供端元数据 554 项、边界替换 45+1 项通过。静态核验 10 个补丁、12 个反射字段，非公开成员直接访问为 0。
- Verified through 73 actual-Unity assertions plus desktop and metadata checks. This is a local Windows validation; it does not establish full multiplayer or cross-platform support.
- Horde 未适配。全部混合配方、完整订单生命周期、ModSettings 实际面板语言刷新及双端多人仍待验收。Horde is unsupported; full mixed-recipe coverage, order lifecycles, live ModSettings visuals, and two-peer multiplayer remain unverified.
