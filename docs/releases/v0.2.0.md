# OC2 HUD 自定义 / OC2 HUD Customization v0.2.0

## 中文

- 新增局内 HUD 编辑器：从 ModSettings 总开关下方进入，使用游戏风格的可拖动面板和类别下拉列表，选中即高亮并预览；本关未创建的类别置灰。
- 计分板、倒计时和切菜、烹饪 / 烤串、搅拌、烧烤火力 / 热力、洗碗、灭火进度支持位置、大小、宽高和不透明度调整。主体可拖动，四边改宽高，四角等比缩放；修改一组，全局同类生效。
- 菜谱可在编辑器中调整大小、每行数量、行间距和不透明度。编辑期间继续展开并平滑重排，关卡与订单计时保持暂停；热力条可预览本关已创建的显示或实际冷炉的临时显示。
- 容器图标支持拖动、拉伸、X/Y、大小、宽高及每行上限；原材料和加号不透明度用两条同时显示的滑块调整。修复新图标组初始化后未正确继承位置的问题。
- 支持保存、取消及恢复当前类别默认值，按反引号 ` 保存退出。新增编辑参数持久保存但不在 ModSettings 逐项显示；保留已有配置和12语言自动跟随，语言未就绪时使用英文。

## English

- Adds an in-game HUD editor beneath the master switch in ModSettings, with a draggable game-style panel and a category dropdown. Selecting a category highlights and previews it; categories not created in the kitchen are disabled.
- Adjust position, scale, width, height and opacity for the score, timer, chopping, cooking / kebab, mixing, barbecue heat, washing and extinguishing displays. Drag the body to move, edges to resize and corners to scale proportionally. Changes apply to every instance of the same category.
- Edit recipe scale, columns, row spacing and opacity. Cards keep unfolding and smoothly rearranging while round and order timers stay paused. Heat previews use displays already created in the kitchen or temporary visuals from an actual cold barbecue station.
- Drag and resize container icons, or adjust X/Y, scale, width, height and icons per row. Ingredient and plus-sign opacity have two simultaneous sliders. Fixes newly created icon groups failing to inherit their position after initialization.
- Save, cancel or reset the current category; press backquote ` to save and exit. Editor settings persist without individual entries cluttering ModSettings. Existing configuration and automatic support for all 12 game languages are retained, with English before the language is available.

## 日本語

- ModSettingsの全体スイッチの下にゲーム内HUDエディターを追加しました。ゲーム風のドラッグ可能なパネルと種類のドロップダウンを使い、選択すると強調表示とプレビューが有効になります。現在の厨房で未生成の種類は選択できません。
- スコア、タイマー、切る・調理 / 串焼き・混ぜる・バーベキュー火力・皿洗い・消火の表示について、位置・大きさ・幅・高さ・不透明度を調整できます。本体をドラッグして移動、辺で縦横を変更、角で比率を保って拡大縮小できます。同じ種類の全表示に適用されます。
- レシピの大きさ、1行の枚数、行間、不透明度を編集できます。編集中もカードの展開と滑らかな再配置が動き、ラウンドと注文のタイマーは停止します。火力プレビューには生成済みの表示、または現在の厨房にある実際の冷えたバーベキュー設備から取得した一時表示を使います。
- 容器アイコンのドラッグ・伸縮に加え、X/Y、大きさ、幅、高さ、1行の上限を調整できます。食材とプラス表示の不透明度スライダーを同時に表示します。新しいアイコン群が初期化後に設定位置を引き継がない問題を修正しました。
- 保存、キャンセル、現在の種類の初期値への復元に対応し、バッククォート ` キーで保存して終了します。編集設定はModSettingsに個別項目を増やさず保存します。既存設定とゲームの12言語への自動追従を維持し、言語取得前は英語を使用します。

## 安装 / Installation

1. 需要 Windows Mono 版《胡闹厨房 2》及 BepInEx 5 / HarmonyX。Requires the Windows Mono build of Overcooked! 2 with BepInEx 5 / HarmonyX.
2. 下载 `OC2HudCustomization-v0.2.0.zip`，将唯一的 `OC2HudCustomization.dll` 放入 `BepInEx/plugins`，覆盖旧版并重启游戏；只保留一份本插件。Extract the DLL into `BepInEx/plugins`, replace the previous copy, and restart the game.
3. 游戏内编辑入口需要 **ModSettings ≥1.1.1**；不装设置面板时，原有 cfg 和已保存的显示参数仍然生效。The in-game editor requires ModSettings ≥1.1.1; saved configuration still applies without the settings panel.
4. 插件 GUID 保持 `com.ch3ngyz.plugin.overcooked2.hudcustomization`，配置路径不变，升级无需删除 cfg。The GUID and configuration path are unchanged; keep your existing cfg.

## 支持范围 / Support

- 编辑器限没有远程玩家的本地普通厨房；当前不支持在多人会话或 Horde / 生存模式中编辑。The editor is limited to a local ordinary kitchen without remote players; multiplayer, Horde and survival editing are unsupported.
- 只调整本机展示，不改变配方、容器容量、处理进度或网络状态；Y为屏幕方向，不提供世界Z偏移。Changes affect local presentation only, not recipes, capacity, processing progress or networking. Position uses screen X/Y, without a world-Z offset.
- 实机验收采用真实Unity中的脚本输入和原生显示对象，不等于物理鼠标/手柄或完整烹饪流程验收。全部12语言的实际字形、所有分辨率、真实冷炉与烤串完整业务及双端多人仍未完整验证。Actual Unity validation uses scripted input and native display fixtures; physical devices, all languages/resolutions, full cold-barbecue/kebab lifecycles and two-peer sessions remain unverified.
